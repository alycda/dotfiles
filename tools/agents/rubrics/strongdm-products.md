# StrongDM Software Factory — Products

> Cached from <https://factory.strongdm.ai/products>

Useful components from StrongDM's Software Factory — listed for awareness, not as required dependencies.

## CXDB

Self-hosted context store for AI agents. Turn DAG, blob deduplication, dynamic types, and visual debugging. A candidate substitution once a project outgrows filesystem-based research artifacts.

## StrongDM ID

Identity for humans, workloads, and AI agents with federated authentication and path-scoped sharing.

## Attractor

A non-interactive coding agent structured as a graph of phases. Runs end-to-end when the work is fully specified — the downstream consumer of well-seeded, well-indexed project artifacts.

### Attractor implementations to know about

- **Fabro** ([fabro.sh](https://fabro.sh/)) — open-source workflow orchestration with graph-based pipelines, verification gates, and Git checkpointing
- **Kilroy** ([github.com/danshapiro/kilroy](https://github.com/danshapiro/kilroy)) — local-first CLI for running Attractor pipelines in a git repo
