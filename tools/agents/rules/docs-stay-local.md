# Agent docs stay local markdown

When you write a document — a spec, plan, draft, writeup, or review artifact —
it is a local markdown file. The deliverable is the file path. Do not publish
it to a hosted service to produce a link unless I ask for that in this session.

The compound-engineering plugin defaults to Proof (Every's hosted service): its
`ce-proof` skill publishes there, and its planning skills hand off through it.
That default is overridden here:

- If a skill or instruction says "publish to Proof" or "hand off via ce-proof",
  write the same markdown to a local file instead and say that you did.
- Use `/ce-proof` only when I invoke it myself, to read or comment on a Proof
  link someone else shared.

When I do ask for a shareable link, ask which destination I want rather than
choosing one.
